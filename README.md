Shopii is an Android-based Shop Management Application developed as a Final Year Project. The app is designed to help small and medium shop owners manage their products, sales, customers, and inventory digitally and efficiently.
.

📌 Features

📦 Product Management (Add, Update, Delete Products)

🧾 Sales Management

👥 Customer Management

📊 Inventory Tracking

🔐 Secure & User-Friendly Interface

📱 Android Mobile Application

🛠️ Technologies Used

Platform: Android

Programming Language: Java

Build System: Gradle

IDE: Android Studio
